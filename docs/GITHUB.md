# dBound · 桌面音量哨兵

> 用麦克风实时估测环境响度：太吵、或朗读时太小声，一眼就能看见。
> Windows 10 1809+ / 11 · Tauri 2 + React 19 + TypeScript · **v1.0.1 Beta2**

[下载安装包](release/dBound_1.0.1_x64-setup.exe)

![主界面](docs/images/defaults-main.png)

## 主要功能

### 🔊 实时响度测量
- 麦克风 RMS 换算分贝（`20·log10(rms) + 校准偏移`），30 Hz 刷新
- 中央超大读数 + 最近 60 秒波形 + 3 秒峰值
- 支持快速 / 慢速 / 朗读平滑三种时间加权，读数不抖

### 🎚 两种模式 · 1–8 级提醒
- **自习课模式**：太吵时按级别提醒
- **早读模式**：太小声时按级别提醒（内置朗读平滑）
- 两种模式可改名，界面 / 全屏 / 日志同步
- 每级独立阈值、名称、提示语、颜色；固定 2s 持续 + 3dB 回差防抖
- 提醒只换色/光晕/呼吸环，不弹窗、不发声

### 🖥 全屏投屏
- F11 一整屏巨大读数，ESC 退出，适合课堂 / 朗读打卡投屏
- 左上角标题、副标题可改文字、字体、字号、颜色
- 级别名称 + 提示语与主界面完全同内容、同颜色
- 达标奖励：底部随机蹦出 Win11 表情，可配置每个模式的触发分贝、持续时长、初始数量（最多 80 个）

### 🪟 迷你窗 · 托盘
- 158×58 置顶胶囊窗，主窗隐藏时仍刷新，点一下回主窗
- 关闭主窗自动进托盘，托盘菜单可切主窗 / 迷你窗 / 退出

### 🎨 外观
- 极光 / 薄荷两套浅色柔光渐变背景（缓慢漂移 + 细颗粒质感）
- 暗黑模式（与主题叠加），主窗、设置、日志、全屏、迷你窗统一
- 可调：数字滚筒动画时长与刷新间隔、未命中时数字颜色、状态文字与级别文字的字号/颜色
- 自绘平滑滚动条，长设置页拖动手感更稳

### 📼 证据录制 · 现场快照（隐私优先）
- 平时音频只在内存中循环保留最近 5 秒，**不写盘**
- 命中警报时保存「前 5 秒 + 后 10 秒」单声道 16 kHz WAV
- 可选摄像头快照：触发瞬间抓一张 JPG，与 WAV 同时间戳、同目录
- 录音 / 照片可按「自习课 / 早读」分别开关；保存目录可自定义
- 全程本机处理，不上传

### 🎛 校准 · 设备 · 日志
- 偏移量滑杆 + 「安静环境校准」「朗读校准」一键校准
- 麦克风与摄像头设备选择
- 应用内日志中心：触发事件 + 每秒采样，按日/类型筛选、搜索、导出 CSV

### 📦 安装与授权
- NSIS 安装包，安装时校验序列号、可自定义安装路径
- 安装目录完整（程序 + 卸载器 + 文档），开始菜单快捷方式，静默卸载干净
- 首次启动校验激活标记；复制安装目录到其他电脑需重新输入序列号

## 说明

- 读数用于比较响度的相对大小，不是声级计的计量结果
- 不同麦克风差异可达 10dB，请用「校准」对齐使用场景
- 安装序列号随授权提供，请勿公开传播
